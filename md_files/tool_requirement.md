# tool_requirement.md

이 문서는 지금까지 사용자가 이 프로젝트(ai-gui-builder-app)에 대해 지시한 요구사항을 시간 순서대로 요약한 것이다.

## 1. 프로젝트 기본 방향 (CLAUDE.md)

- 사용자가 코딩 없이 자신이 원하는 간단한 툴(GUI 앱)을 직접 만들 수 있는 프로그램을 제공한다.
- 사용자가 참고할 수 있는 기본 예제를 제공한다.
- 사용자가 만든 툴은 빌더/`claude` CLI 없이 standalone으로 실행 가능해야 하며, 원하는 위치에 저장할 수 있어야 한다.
- 프로그램 실행 시 참고용 예제가 화면에 보이도록 한다.
- 사용자가 지시하는 작업은 진행할지 묻지 말고 바로 실행한다 (단, 되돌리기 힘든 파괴적인 작업은 신중하게 판단).

## 2. 캔버스 창

- 창 제목을 "나만의 tool"로 변경, 상단 "파일" 메뉴는 제거 (내보내기는 팔레트의 저장 버튼으로 대체).
- 탭(화면) 관리:
  - 기본 탭 이름을 "화면 1" → "tab 1"로 변경.
  - 탭 영역의 빈 공간을 오른쪽 클릭하면 새 탭이 생성됨.
  - 탭을 오른쪽 클릭하면 메뉴 3개가 뜬다: **delete**, **탭 제목 편집**, **바탕색**.
    - delete → "이 탭을 지울까요?" Yes/No 확인 팝업, Yes 시 삭제 (마지막 탭은 삭제 불가).
    - 탭 제목 편집 → 입력창 + Yes/No, Yes면 제목 변경, No면 아무 변화 없이 닫힘.
    - 바탕색 → 색상 선택 창에서 고르면 해당 탭의 배경 전체 + 탭 제목이 표시된 작은 영역까지 그 색으로 채워짐 (탭 제목 텍스트 자체는 안 바뀜).
  - 탭을 왼쪽 마우스로 누른 채 좌우로 끌면 다른 탭 사이로 순서를 옮길 수 있음 (배경색도 탭을 따라 함께 이동).
  - 탭 영역과 캔버스 콘텐츠 영역 사이의 가로 구분선 제거.
- 앱을 껐다 켜도 이전에 만든 탭/위젯 구성이 사라지지 않고 그대로 복원되어야 한다 (자동 저장/복원).

## 3. 위젯 팔레트

- 저장 버튼 위에 **"틀 저장"** 버튼 추가 — 누르면 지금까지 만든 탭/위젯 구성(빌더 자체 상태)을 저장.
- 기존 "저장" 버튼은 **"standalone 저장"**으로 이름 변경 — 누르면 디렉토리를 선택해 독립 실행 가능한 앱으로 내보내기.
- 팔레트에 **가로선/세로선** 위젯 추가, 드래그해서 캔버스에 놓을 수 있음.
- 팔레트에 **URL 입력창**/**디렉토리 입력창** 위젯 추가. 둘 다 텍스트박스(QLineEdit) 기반이라 이동/
  크기조절/색깔/이름변경/폰트설정/저장복원/복사붙여넣기 등 기존 로직을 그대로 재사용.
  - 둘 다 오른쪽 끝에 아이콘 버튼이 내장됨(`QLineEdit.addAction`, 합성 위젯 아님이라 기존 인프라와
    100% 호환): 디렉토리 입력창은 폴더 아이콘 → 디렉토리 선택 창; URL 입력창은 네트워크 아이콘 →
    URL을 입력할 수 있는 작은 팝업 창(`QInputDialog`). 두 아이콘 다 직접 타이핑도 여전히 가능.
  - 이 아이콘/팝업 동작은 standalone 내보내기에도 그대로 포함됨 (`_browse_directory`/`_prompt_url`
    헬퍼 함수를 내보낸 `.py`에도 똑같이 심어줌).

## 4. 캔버스 위 위젯(버튼/드롭박스/텍스트박스/선) 조작

- 위젯을 마우스로 눌러서 끌면 캔버스 안에서 위치 이동 가능 (클릭 동작과 충돌하지 않게 처리).
- 위젯 가장자리를 누르면 커서가 바뀌고, 눌러서 끌면 크기 조절 가능 (8방향 + 최소 크기 제한).
  - 가로선/세로선은 두께 축은 고정, 길이 축만 크기 조절됨. 기본 두께는 처음 대비 총 6배(6→12→36px)로 확대.
- 위젯을 오른쪽 클릭하면 메뉴가 뜸: **동작 설정...**, **색깔 변경**, **이름 변경**(텍스트가 있는 위젯만; 드롭박스/선 등은 이름 변경 메뉴 제외), **폰트 설정**(텍스트박스만; 폰트 종류/크기 선택).
  - 선(가로선/세로선)은 클릭 동작이 없는 위젯이라 "동작 설정..." 메뉴 자체가 안 뜸.
- 캔버스 빈 공간에서 마우스로 박스를 그려(러버밴드) 여러 위젯을 한번에 선택 가능.
  - 선택된 상태에서 **Delete/Backspace** 키를 누르면 선택된 위젯들을 전부 삭제.
  - 선택된 상태에서 **Ctrl+C**로 복사, **Ctrl+V**로 붙여넣기 — 원본에서 (20,20)px 오프셋된 위치에 텍스트/색/크기/연결된 동작까지 그대로 복제됨. 클립보드는 탭 간에도 공유되어 다른 탭에도 붙여넣기 가능.

## 5. 저장/내보내기(standalone) 관련

- 팔레트의 "standalone 저장" 버튼 = 사용자가 디렉토리를 선택하면 그 안에 독립 실행 `.py` 파일로 저장. 빌더나 `claude` CLI 없이 PySide6만 있으면 실행됨.
- 여러 탭으로 나눠 만든 내용도 standalone 앱에 탭 구조 그대로 반영되어야 함 (처음엔 활성 탭만 내보내던 버그를 전체 탭 반영하도록 수정).
- 각 위젯의 이름(텍스트)/색깔/크기/폰트도 standalone 내보내기에 그대로 반영되어야 함.

## 6. 동작 코드에서 쓸 수 있는 함수(화이트리스트) 확장

- "동작 설정"으로 생성되는 코드가 파일/디렉토리/인터넷 관련 요청을 거부하는 문제가 있었음(예: 디렉토리
  파일 목록 조회, 하위 디렉토리 생성, 인터넷에서 가져온 문서를 md로 변환 저장) — 기존 화이트리스트
  (`open_url`/`read_file`/`write_file`/`delete_file`)에 아래를 추가:
  - `list_dir(path)` — 디렉토리 내 파일/폴더 이름 목록 반환
  - `make_dir(path)` — 디렉토리(하위 포함) 생성
  - `fetch_url(url)` — http/https URL 내용을 문자열로 가져옴 (open_url과 동일한 스킴 제한). 기본
    `urllib`의 User-Agent로는 403 Forbidden을 리턴하는 사이트가 많아서, 브라우저처럼 보이는
    User-Agent(Chrome UA 문자열)를 붙여서 요청하도록 수정함 (`code_binder.py`/`exporter.py` 둘 다).
  - `html_to_markdown(html)` — HTML을 마크다운으로 변환 (`markdownify` 패키지 사용, requirements.txt에 추가)
- "이미지 파일 분류" 요청: 구체적 방식(내용 분석 vs 파일명/확장자 기준)을 물어봤으나 사용자가 대신
  **라디오 버튼 위젯**을 만들어 방식을 선택할 수 있게 해달라고 요청 → 팔레트에 "라디오 버튼" 위젯 추가로
  대응 (아래 7번 참고). 분류 로직 자체(claude CLI 내용 분석 등)는 아직 미구현 — 라디오 버튼으로 옵션을
  고르는 UI만 준비된 상태.

## 7. 라디오 버튼 위젯 추가

- 팔레트에 **라디오 버튼** 위젯 추가. 다른 위젯과 동일하게 이동/크기조절/색깔/이름변경/저장·복원/
  복사·붙여넣기/standalone 내보내기 지원.
- "동작 설정" 가능 (`clicked` 시그널에 연결), 생성 코드에서 `self.<id>.isChecked()`로 선택 여부 확인.
- 라디오 버튼 우클릭 메뉴에 **옵션 추가**/**옵션 제거** 추가: 추가하면 바로 아래에 새 라디오 버튼이 자동
  생성(`옵션 <번호>` 라벨, 같은 그룹), 제거하면 그 라디오 버튼 삭제(선택 상태였던 위젯을 여러 개 지우는
  기존 Delete 키 로직과 코드 공유 — `_remove_widget` 헬퍼로 통합).
- **그룹 독립성 버그 수정**: 처음엔 같은 탭(부모 위젯)에 놓인 라디오 버튼이 전부 Qt의 기본 동작으로
  하나의 그룹으로 묶여서, 서로 다른 의미의 라디오 그룹(예: "성별" vs "크기")을 같은 화면에 둘 수 없었음.
  `QButtonGroup` + `setAutoExclusive(False)`로 명시적 그룹 관리를 도입해 해결:
  - 각 라디오 버튼 entry에 `group` 필드를 두고, 팔레트에서 새로 드래그한 라디오는 자기 자신의 id를
    자기 그룹으로 시작(= 독립 그룹). "옵션 추가"로 만든 라디오만 원본과 같은 group을 물려받음.
  - `group`도 저장/복원, 복사·붙여넣기, standalone 내보내기(탭별로 `QButtonGroup` 여러 개 생성)에
    전부 반영됨.
- **각 그룹의 첫 번째 라디오 버튼을 기본 선택**: 그룹에 처음(= 유일한 멤버로) 추가되는 라디오 버튼을
  자동으로 `setChecked(True)`. "옵션 추가"로 나중에 합류하는 버튼은 체크하지 않아 기존 선택을
  안 건드림. 상태 저장은 안 하고 매번 "그룹의 첫 멤버" 규칙을 다시 적용하는 방식이라, 복원/내보내기
  시에도 각 그룹의 (엔트리 순서상) 첫 번째 라디오가 항상 기본 선택됨.

## 8. 위젯 우클릭 메뉴에 ID 표시

- 모든 위젯(드롭박스/버튼/텍스트박스/URL 입력창/디렉토리 입력창/라디오 버튼 등)을 우클릭하면 메뉴 맨
  위에 "ID: <위젯id>"가 비활성(클릭 불가) 상태로 항상 표시됨. 다른 위젯의 "동작 설정"에서 이 위젯을
  `self.<id>`로 참조할 때 참고하라는 목적.

## 9. 텍스트박스류 테두리 없애기

- 텍스트박스/URL 입력창/디렉토리 입력창 우클릭 메뉴에 **"테두리 없애기"** 추가. 누르면
  `QLineEdit.setFrame(False)`로 그 위젯의 테두리를 바로 제거. entry에 `no_border` 플래그로 기록해
  저장/복원, 복사·붙여넣기, standalone 내보내기에 전부 반영됨. 되돌리는 메뉴는 없음(요청 범위 밖).

## 10. `QInputDialog` 실행 오류 수정

- 실제 사용 사례: URL 입력창의 문서를 가져와 md로 변환해 디렉토리 입력창 경로에 저장하는 동작을
  자연어로 지시했더니, 파일명을 입력받는 팝업이 필요해서 Claude가
  `from PySide6.QtWidgets import QInputDialog`를 코드에 직접 넣었고, 이게 빌더의 제한된 실행 환경에서
  `ImportError: __import__ not found`로 크래시남 (import 문 자체가 exec 샌드박스에서 금지되어 있음).
- 수정: `QMessageBox`처럼 `QInputDialog`도 화이트리스트에 미리 넣어 항상 사용 가능하게 함
  (`code_binder.py`의 `compile_handler` 네임스페이스, `ai_client.py` 시스템 프롬프트에 사용법 명시,
  `exporter.py`는 이미 import되어 있어 추가 조치 불필요).
- 실행 오류 메시지도 개선: `ImportError`가 나면 "import는 금지되어 있고 이 함수들만 쓸 수 있다"는
  안내와 함께 사용 가능한 함수 목록을 보여주도록 `bound_handler`의 예외 처리를 분리함.
- 같이 요청됐던 "이미지 파일 분류"(라디오 버튼으로 방식 선택: 자동 분류 vs claude에게 요청)는 처음엔
  실제 로직 없이 안내 팝업만 뜨는 상태였음 → 사용자에게 확인해서 구체화됨: 이미지는 URL에서 가져온
  HTML의 `<img>` 태그에서 옴, "분류"는 내용을 보고 주제별 하위 폴더에 저장하는 것, radiobutton_1(자동)은
  alt 텍스트/파일명 키워드 매칭, radiobutton_2(claude 요청)는 이미지마다 `claude` CLI를 순차 호출해서
  실제 분류(속도보다 정확도 우선, 여러 장이면 그만큼 느림 — 확인 완료). → 12번 참고.

## 11. 웹 이미지 다운로드/분류 화이트리스트 함수 추가

- `code_binder.py`/`exporter.py`(standalone)에 아래 3개 함수 추가:
  - `extract_images(html, base_url)` — `fetch_url`로 가져온 html의 모든 `<img>` 태그를
    `[{"url": 절대경로, "alt": alt텍스트}, ...]`로 반환 (`BeautifulSoup` 사용, `bs4`는 markdownify의
    기존 의존성이라 이미 설치되어 있었음 — `requirements.txt`에 `beautifulsoup4` 명시적으로 추가).
  - `download_file(url, path)` — http(s) URL의 바이너리 내용을 그대로 저장 (fetch_url은 텍스트 전용).
  - `classify_image_with_claude(path)` — 로컬 이미지를 `claude -p`로 보여주고 폴더명으로 쓸 수 있는
    영문 소문자 카테고리 단어를 받음. CLI 없음/타임아웃/빈 응답이면 "기타"로 안전하게 폴백.
- 이 흐름에서 다운로드한 이미지를 분류 폴더로 옮길 때 `read_file`/`write_file`(텍스트 전용)을 쓰면
  이미지가 깨지는 버그를 미리 발견해서, 바이너리 안전한 `move_file(src, dst)`(`shutil.move` 래핑)도
  같이 추가함.
- `ai_client.py` 시스템 프롬프트에 이 함수들의 사용법과 "다운로드 → 분류 → 하위폴더로 move_file" 예시
  흐름을 추가해서, 앞으로 비슷한 요청에서 Claude가 이 함수들을 바로 활용하도록 함.
- `classify_image_with_claude`는 실제 `claude` CLI를 호출하므로 사용자 사용량을 소모함 — 테스트는
  `subprocess.run`을 모킹해서 폴백/파싱 로직만 검증했고, 실제 CLI 호출 자체는 실행하지 않음.

## 12. `fetch_url`/`download_file` 429(Too Many Requests) 재시도

- 이미지 여러 장을 연달아 `download_file`로 받다가 대상 서버가 429로 거절하는 사례 발생.
  `_urlopen_with_retry`를 추가해서 429를 받으면 `Retry-After` 헤더(없으면 지수 백오프, 최대 10초)만큼
  기다렸다 최대 3회까지 재시도하도록 `fetch_url`/`download_file` 둘 다 수정 (`code_binder.py`/
  `exporter.py` 동일 적용). 재시도를 다 써도 안 되면 원래 예외(HTTPError)를 그대로 올림.

## 13. 알람 시계 위젯 (완전히 새로운 종류의 위젯)

- 요청: "alarm" 탭에 알람 시계 기능 — 일회성/주기적 알람 추가 버튼, 일회성은 날짜→시간 선택, 주기적은
  시작/끝 날짜+반복 요일→시간 선택, 등록된 알람은 아래 목록에 남은 시간과 함께 표시, 오른쪽 위에
  아날로그 시계.
- 이건 기존의 "단순 위젯 + 자연어로 동작 붙이기" 모델로는 못 만드는 수준(달력/시간 선택 다이얼로그,
  실시간 카운트다운, 커스텀 페인팅 아날로그 시계, 지속적인 QTimer)이라, **완전히 새로운 전용 위젯**을
  만들어서 대응함:
  - `alarm_widget.py` 새 모듈 — `AnalogClock`(QPainter로 직접 그리는 시계, 1초마다 갱신),
    `AlarmClockPanel`(추가 버튼 2개 + 알람 목록 + 아날로그 시계를 담은 합성 위젯), 날짜/시간/기간+요일
    선택용 내부 다이얼로그 3종.
  - `canvas_window.py`의 `WIDGET_FACTORIES`에 `"alarmclock"` 키로 등록, 팔레트에도 "알람 시계"로 추가.
    기본 크기 420×320 (`LINE_DEFAULT_SIZE` 딕셔너리 재사용 — 이름은 그대로 두고 다른 위젯 종류의 기본
    크기도 같이 담당하게 확장).
  - 다른 위젯과 달리 "동작 설정"/"이름 변경"/"폰트 설정" 메뉴는 안 뜸 (텍스트/시그널 개념이 없음).
    "색깔 변경"은 됨 (일반 QWidget 배경색 로직 그대로 적용).
  - **알람 데이터 자체는 저장 대상이 아님** — 위젯의 위치/크기만 다른 위젯처럼 저장/복원되고, 등록해둔
    알람 리스트는 앱 재시작 시 초기화됨 (범위 밖으로 판단, 필요하면 나중에 추가 가능).
  - standalone 내보내기: `alarm_widget.py` 파일을 손으로 다시 베껴서 문자열 템플릿에 넣는 대신,
    **실제 파일 내용을 그대로 읽어서 내보낸 코드에 통째로 삽입**하는 방식 사용 (`exporter.py`의
    `_read_alarm_widget_source()`) — 빌더와 내보낸 앱의 구현이 서로 어긋날 일이 없음. 알람 시계를 안
    쓰는 탭을 내보낼 땐 이 소스를 아예 안 넣어서 불필요하게 커지지 않게 함.
  - 실제 화면 렌더링(analog clock 얼굴+바늘, 버튼, 목록) 스크린샷으로 확인, 알람 등록/카운트다운/
    지난 알람 자동 발화+목록에서 사라짐/서로 다른 요일 반복 로직까지 전부 단위 테스트로 검증,
    export된 standalone 앱도 실제로 띄워서 에러 없이 뜨는 것까지 확인함.
  - 버그 하나 발견 후 수정: `QPen(color, width, cap=...)` 생성자에 `cap` 키워드가 PySide6에서 안 먹혀서
    (`unsupported keyword 'cap'`), `pen.setCapStyle(...)`을 별도로 호출하는 방식으로 고침.

## 14. 알람 시계를 팔레트에서 빼고 "alarm" 탭에 고정 배치

- 사용자 요청으로 팔레트의 "알람 시계" 드래그 항목 제거 (`palette_window.py`의 `DraggableAlarmClock`
  삭제). `WIDGET_FACTORIES`의 `"alarmclock"` 등록 자체는 유지 (내보내기/불러오기가 이 kind로 계속
  동작해야 하므로).
- 대신 이미 존재하던 "alarm" 탭(`builder_state.json`에 비어있는 상태로 있었음)에 `alarmclock_1` 위젯을
  직접 상태 파일에 추가해 넣어줌 — 앱을 껐다 켤 필요 없이 바로 "alarm" 탭에 알람 시계가 보이는 상태로
  시작하게 함. (주의: 상태 파일을 직접 수정한 뒤에는 반드시 앱을 재시작해서 새 상태를 메모리로
  로드해야 함 — 안 그러면 기존에 실행 중이던 프로세스가 닫힐 때 메모리상의 예전 상태로 덮어씀.)

## 15. 알람 시계 위젯 개선 (4가지)

1. **알람 팝업을 20cm×20cm 정사각형 창으로**: 기존 `QMessageBox.information` 대신 전용 `_AlarmPopup`
   (QDialog) 추가. `QApplication.primaryScreen()`의 DPI로 cm→px 환산(`_cm_to_px`, main.py의 로직과
   동일한 공식). 메시지는 알람 등록 시 입력한 텍스트를 그대로 표시.
2. **알람 메시지 입력란**: `_TimePickerDialog`(일회성/주기적 흐름에서 공통으로 마지막에 쓰이는 시간
   선택 창)에 메시지 `QLineEdit` 추가. 기본값 "시간이 됐어요 !!" (`DEFAULT_ALARM_MESSAGE` 상수), 비워서
   확인하면 기본값으로 대체.
3. **알람별 × 삭제 버튼**: 알람 목록을 단순 텍스트 `QListWidgetItem`에서, `QLabel`(정보) + `QPushButton("×")`
   를 담은 행 위젯을 `setItemWidget`으로 붙이는 방식으로 변경. 버튼을 누르면 그 알람의 `id`로 찾아서
   `_alarms`에서 제거 후 목록 갱신.
4. **크기 2배**: 아날로그 시계 90×90 → 180×180. 패널 기본 크기 420×320 → 840×640
   (`canvas_window.LINE_DEFAULT_SIZE["alarmclock"]`) — 이미 "alarm" 탭에 배치해둔 위젯의
   `builder_state.json` 항목도 같은 크기로 함께 수정.
- 팝업 크기/메시지/삭제 동작/크기 변경까지 전부 단위 테스트로 확인 (팝업은 `.exec()`를 모킹해서
  실제 이벤트루프 블로킹 없이 검증), standalone 내보내기 재생성도 반영 여부 확인함.
